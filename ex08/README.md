ex08 物联网安防报警器模拟实验
 关联基础实验
1. 基础IO输入输出实验
2. 实验4：ESP32触摸引脚读取、边沿检测、软件防抖
3. Web服务器网页交互实验

 实验需求
1. ESP32作为安防主机，搭建网页服务，页面设置「布防Arm」「撤防Disarm」两个控制按钮
2. 使用全局变量维护系统布防状态、报警自锁状态
3. 系统未布防时，触摸感应引脚不会产生任何动作
4. 系统布防状态下：一旦触碰触摸引脚，LED高频闪烁进入锁定报警；松手后报警不会自动停止
5. 仅能通过网页点击「撤防」按钮，熄灭LED、清除报警、重置系统状态
 WiFi配置
- 热点名称：zcc的ipone
- 热点密码：88888888
 硬件引脚分配
| 功能 | ESP32引脚 | 说明 |
|------|-----------|------|
| 触摸入侵检测引脚 | GPIO4(T0) | 电容触摸检测，触碰触发报警 |
| 报警指示灯 | GPIO2 | ESP32板载LED，报警时快速闪烁 |

 触摸参数适配
本机实测触摸读数：
- 手指触摸 ≈ 350
- 无触摸 ≈ 1000
判定阈值 threshold=600，数值小于阈值判定有效触摸动作；搭配50ms软件防抖+上升沿检测，防止误触发。

 核心工作原理
 1. 双全局状态变量
- `bool isArm`：系统总开关，true=布防警戒，false=撤防休眠
- `bool isAlarmTrigger`：报警自锁标志，一旦置true，持续触发LED闪烁，仅撤防可清零

 2. 网页交互逻辑
1. 访问ESP32IP主页，展示两个功能按钮+状态提示文字
2. 点击【布防】：浏览器发起GET请求 `/arm`，ESP32置位布防状态
3. 点击【撤防】：浏览器发起GET请求 `/disarm`，ESP32关闭报警、复位全部状态

 3. 报警触发逻辑
- 未布防：无论是否触摸，系统无响应
- 已布防 + 检测到触摸上升沿 → 置位报警标志，LED高频循环闪烁自锁
- 报警启动后，松开触摸引脚不会停止闪烁，必须网页撤防解除

 实验运行现象
1. ESP32连接手机热点，串口打印局域网访问IP
2. 同热点设备打开网页，默认状态：已撤防，触摸引脚无反应
3. 点击网页【布防】，系统进入警戒模式
4. 手指触碰GPIO4触摸引脚，LED立刻快速闪烁报警，手拿开依旧持续闪烁
5. 点击网页【撤防】，LED熄灭，报警解除，回到休眠状态，等待下次布防

 调试注意事项
1. 控制端手机/电脑必须和ESP32连接同一个手机热点
2. 网页空白优先检查WiFi名称、密码拼写是否正确
3. 触摸灵敏度异常可微调threshold阈值适配环境
