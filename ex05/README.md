 ex05 多档位触摸调速呼吸灯
关联前置实验
1. 实验3：PWM 模拟呼吸灯原理与实现
2. 实验4：ESP32 触摸引脚读取、边沿检测、触摸自锁防抖逻辑

项目功能
基于PWM呼吸灯程序，叠加触摸触发档位切换逻辑：
一共3档呼吸速度，上电默认1档慢速；
每触摸一次触摸引脚，档位循环切换：`1 → 2 → 3 → 1`；
档位越大，LED明暗呼吸节奏越快，搭配上升沿检测+软件防抖，防止手抖误触发。

硬件引脚分配
| 功能模块 | ESP32 引脚 | 说明 |
|--------|------------|------|
| 电容触摸输入 | GPIO4（触摸通道T0） | 触摸档位切换触发引脚 |
| PWM呼吸LED输出 | GPIO2 | ESP32板载LED，PWM调光 |

实测触摸参数说明
本机触摸引脚实测采样值：
- 手指未触摸：touchRead ≈ 1000
- 手指触摸：touchRead ≈ 350
触摸时采样数值变小，设置判定阈值 `threshold = 600`；
采样值＜600 判定为有效触摸动作。

核心工作原理
1. 触摸防抖与边沿检测
设置50ms软件防抖窗口，仅识别「上一刻未触摸、当前瞬间触摸」上升沿事件；
长按、持续触摸不会重复切换档位，抑制手部抖动、电磁干扰造成误触发。

2. 三档位循环逻辑
使用变量 `gear` 存储当前档位，切换公式 `gear = gear % 3 + 1` 实现三档循环轮转。

3. 呼吸调速原理
通过修改PWM亮度增减步长控制呼吸快慢：
- 1档：步长=2 → 亮度变化缓慢，平缓呼吸
- 2档：步长=5 → 中等呼吸速度
- 3档：步长=10 → 亮度变化剧烈，急促呼吸

 实验运行现象
1. 上电初始化，LED默认1档缓慢呼吸
2. 第一次触摸引脚 → 切换2档，呼吸速度中等
3. 第二次触摸引脚 → 切换3档，呼吸节奏急促
4. 第三次触摸引脚 → 切回1档，循环往复
5. 快速连续点触不会乱跳档位，防抖保证触摸稳
调试方式
打开串口监视器，波特率配置 115200，实时查看触摸原始数值与当前档位；
若触摸灵敏度不合适，可微调 `threshold` 阈值适配环境。
