ex03 实验：millis() 实现 SOS 摩尔斯码闪烁
 一、实验要求
1. 创建 ex03 工作目录
2. 使用 millis() 非阻塞定时，LED 输出标准 SOS 信号：
   三短闪 → 三长闪 → 三短闪，一轮结束后长时间熄灭停顿，循环往复
3. Git 至少三次提交记录
4. 拍摄运行照片/视频存入当前文件夹留存实验结果

 二、时序定义
- 单次短亮：200ms
- 单次长亮：600ms
- 同组闪烁间隔：200ms
- S/O 两组之间间隔：600ms
- 完整一轮 SOS 结束停顿：1500ms

 三、原理说明
1. `millis()` 获取上电总毫秒数，采用时间戳判断实现非阻塞定时，不会阻塞 loop 循环；
2. 状态机分段依次执行：S(三短) → O(三长) → S(三短)，一轮结束复位从头循环；
3. 串口波特率115200，一轮SOS结束自动打印提示信息。

四、操作步骤
1. 在项目根目录新建 ex03 文件夹；
2. 新建 .gitignore 过滤编译垃圾文件；
3. 编写 millis 状态机 SOS 源码；
4. Arduino 选择 ESP32 Dev Module，编译上传程序；
5. 观察LED闪烁是否符合 SOS 编码规则；
6. 拍摄运行照片/视频放入 ex03；
7. 分三次提交 Git 并推送远程仓库。

五、实验总结
使用 millis 状态机方式可以实现多段时序复杂灯光逻辑，相比多层 delay 嵌套，程序非阻塞、扩展性更强，便于后续添加其他并行任务。
