 ex09 实时传感器Web仪表盘
 关联前置实验
1. 实验4：ESP32触摸引脚电容采样读取
2. Web服务器基础实验：网页部署、GET路由处理、前后端交互

 实验需求
1. 实现双向Web交互：不仅ESP32下发HTML页面，同时实时采集触摸传感器数据并主动上报网页端
2. 网页使用AJAX（fetch+定时器轮询）不间断获取传感器原始数据
3. 页面做成仪表盘样式，中央实时动态显示触摸采样数值
4. 现象：手指靠近引脚数值实时变小，手指离开数值回升，实时监测电容变化

 WiFi配置
- 热点名称：zcc的ipone
- 热点密码：88888888

硬件引脚
| 功能 | ESP32引脚 | 说明 |
|------|-----------|------|
| 电容触摸传感器输入 | GPIO4(T0) | 实时采集触摸原始采样值 |

 触摸硬件参数
本机实测采样规律：
- 手指触碰/靠近引脚：touchRead ≈ 350（数值变小）
- 无触摸、手指远离：touchRead ≈ 1000（数值变大）

 前后端交互原理1. ESP32后端路由设计
1. 根路径 `/`：响应HTML仪表盘页面，内嵌AJAX自动刷新JS脚本
2. 数据接口 `/getTouchData`：实时读取触摸原始值，以纯文本形式返回，作为数据上报接口

2. 前端AJAX自动轮询
- JavaScript `setInterval` 定时器每100ms发起一次GET请求
- 异步拉取最新传感器数值，局部刷新页面数字，**不需要整页刷新**
- 网络异常自动提示连接故障，提升稳定性
3. 数据流方向
触摸引脚采集数据 → ESP32实时读取 → Web接口对外输出 → 浏览器AJAX持续拉取 → 网页仪表盘实时更新显示

运行步骤
1. 开启手机热点 `zcc的ipone`
2. 上传代码，ESP32连接热点，串口查看分配的局域网IP
3. 控制设备连接同一个热点，浏览器输入IP进入仪表盘
4. 靠近、移开触摸引脚，观察网页数字实时变化
 常见调试问题
1. 网页空白：检查WiFi名称、密码拼写，确认ESP32是否成功联网获取IP
2. 数字不跳动：确认访问 `/getTouchData` 能否单独看到不断变化的数字
3. 数值变化不灵敏：可修改轮询间隔（修改setInterval第二个参数，单位毫秒）
