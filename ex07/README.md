 ex07 Web网页端无极调光器
 关联基础实验
1. 实验3：PWM呼吸灯，掌握 ledcAttach 新式PWM配置、ledcWrite亮度调节
2. Web服务器基础实验：ESP32创建网页、HTTP GET请求处理

 实验需求
1. 搭建ESP32 Web服务，网页内嵌滑动条 `<input type="range" min="0" max="255">`
2. JavaScript监听滑动条变化，使用fetch()发送GET请求上传亮度数值
3. ESP32解析URL参数，修改PWM输出占空比，实现LED无级亮度调节
4. 拖动滑块，LED亮度实时平滑同步变化

 硬件引脚
- LED控制引脚：GPIO2（ESP32板载LED）

 WiFi配置
- 热点名称：zcc的ipone
- 热点密码：88888888

工作原理
1. ESP32连接手机热点，获取局域网IP，开启80端口网页服务器
2. 访问根路径 `/` 返回内嵌滑动条的HTML页面
3. 拖动滑块触发JS事件，`fetch("/set?bright=亮度值")` 发送HTTP GET请求
4. ESP32监听 `/set` 路由，提取`bright`参数，限定0~255范围
5. 通过 `ledcWrite()` 修改PWM占空比，实时改变LED亮度

PWM配置（与实验3完全统一）
- PWM频率：5000Hz
- 分辨率：8位，亮度区间 0 ~ 255
- API：ledcAttach() 自动分配PWM通道，无需手动定义通道号

实验现象
1. 设备连网成功后串口打印访问IP地址
2. 浏览器打开页面，显示横向滑动条+实时亮度数字
3. 滑块拖到最左（0）：LED熄灭
4. 滑块拖到最右（255）：LED最亮
5. 拖动中间位置，LED亮度平滑实时跟随变化

调试说明
1. 必须保证电脑/手机和ESP32连接**同一个手机热点**
2. 若网页无响应，查看串口IP是否正确，核对WiFi名称、大小写、密码
