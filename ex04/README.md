ESP32 触摸自锁开关
项目简介
本项目基于 ESP32 内置触摸检测引脚，在原有「触摸点亮、松开熄灭」电平触发触摸程序（实验4）基础上进行升级改造，实现**触摸单次触发翻转自锁功能**：触碰一次LED长亮，再次触碰LED熄灭；搭配边沿检测逻辑与软件防抖，消除手部抖动、传感器杂波造成的误触发，完成触摸自锁开关实验。
关联实验：基础IO输入输出实验、ESP32触摸引脚读取实验（实验4）

 硬件信息
引脚定义
- 触摸检测引脚 TOUCH_PIN：GPIO4（对应内部触摸通道 T0）
- LED控制引脚 LED_PIN：GPIO2（ESP32开发板自带板载LED）
 硬件清单
1. ESP32 开发板 ×1
2. USB数据线 ×1

工作原理
1. ESP32触摸特性
   `touchRead()` 读取触摸原始值：手指触碰引脚时电容变化，返回数值变小；无触摸时返回数值偏大。程序通过阈值 `threshold` 区分触摸/未触摸状态。

2. 自锁核心逻辑（布尔状态变量）
   定义布尔变量 `ledState` 存储LED当前亮灭状态，不再实时跟随触摸电平变化；仅收到有效触摸事件时对该变量取反，实现状态锁存。

3. 上升沿边沿检测
   记录上一时刻触摸状态 `lastTouchState`，仅判定「上一次未触摸、当前瞬间触摸」这个上升沿事件，只有触碰瞬间才翻转LED，长按、持续触摸不会反复切换灯光。

4. 软件防抖机制
   使用 `millis()` 非阻塞式计时，设置50ms防抖窗口期，过滤触摸信号瞬时跳变、手指轻微抖动带来的误触发，提升触摸稳定性。
