lab03 ESP32 PWM呼吸灯实验
 一、实验概括
实验使用ESP32新版ledc简化PWM语法，通过循环修改PWM占空比实现LED渐亮渐暗呼吸效果；分为两个版本代码：初始版本固定延时，修改延时版本调节呼吸速度，理解delay数值对呼吸快慢的影响，完成程序编译、烧录、调试。

 二、代码说明
1. breath_original.ino 初始源代码
固定 `delay(10)`，亮度步进间隔固定，呼吸速度中等。
核心函数：
- ledcAttach(pin,freq,res)：一键绑定引脚、PWM频率、分辨率
- ledcWrite(pin, duty)：直接引脚输出PWM占空比控制亮度

 2. breath_modify_speed.ino 修改呼吸速率版本
修改两处delay数值：
数值变大 → 单次亮度变化间隔更长，整体呼吸变慢
数值变小 → 单次亮度变化间隔更短，整体呼吸变快
本示例修改为delay(30)，呼吸节奏更缓慢柔和。

 三、实验操作要点
1. 硬件：ESP32通过USB连接电脑，使用板载GPIO2引脚LED
2. IDE配置：开发板选择 ESP32 Dev Module，选择对应COM端口
3. 依次上传两段代码，观察快慢差异
4. 串口监视器波特率115200，可查看单次呼吸循环完成打印信息

四、课后思考题解答
1. 非线性呼吸优化
原程序线性增减PWM占空比，但人眼对亮度感知呈对数非线性，线性观感生硬。可利用`sin()`正弦函数映射0~255亮度值，亮度变化两头慢、峰值平缓，呼吸视觉更柔和；也可使用指数函数实现非线性调光。

2. RGB LED彩虹渐变实现思路
配置三路独立PWM通道分别驱动红、绿、蓝三色LED；分三段循环调节三路占空比：
红递减绿递增（红转绿）→ 绿递减蓝递增（绿转蓝）→ 蓝递减红递增（蓝转回红），循环运行实现连续彩虹渐变。
