 ex02 实验：基于 millis() 实现 1Hz LED 非阻塞闪烁
 一、实验目的
1. 理解 `millis()` 函数作用：返回开发板上电运行总毫秒值，用于实现非阻塞定时，区别于阻塞式 `delay()`。
2. 使用 `millis()` 时间差值判断，编写程序控制LED实现 **1Hz 稳定闪烁**（周期1s：亮500ms、灭500ms）。
3. 熟悉Git版本管理，规范仓库文件，配置.gitignore过滤冗余编译文件。

二、硬件信息
主控：ESP32
LED引脚：GPIO2（板载自带LED）
连接方式：USB直连电脑供电烧录

三、函数原理说明
1. `millis()`：上电后持续累加的毫秒计数器，程序运行全程不会暂停。
2. 定时逻辑：记录上一次翻转时间，用当前总时间减去上次时间，达到设定间隔后翻转LED状态，全程不会阻塞 `loop()` 循环，可并行执行其他任务。
3. 1Hz 定义：频率1赫兹 = 周期1000ms，高低电平各占500ms。

 四、代码文件
文件名：`led_1hz_millis.ino`
功能：非阻塞式 1Hz LED 闪烁

 五、实验步骤
1. 在项目根目录创建 `ex02` 工作文件夹；
2. 新建 `.gitignore` 屏蔽无用编译文件；
3. 编写 `millis()` 定时闪烁源码；
4. Arduino IDE 选择开发板 `ESP32 Dev Module`、对应COM端口；
5. 编译上传程序，观察LED是否每秒翻转一次；
6. 分阶段Git提交，最终推送GitHub远程仓库。

 六、实验小结
- `delay()` 会阻塞整个程序，等待期间无法运行其他代码；
- `millis()` 时间戳判断为非阻塞定时，是嵌入式多任务常用写法。
