 lab01 ESP32 LED 闪烁实验
一、实验目的
1. 验证 Arduino IDE 与 ESP32 开发板环境配置正常，掌握代码上传方法。
2. 学习 GPIO 引脚输出配置，实现 LED 灯控。
3. 理解 delay()`延时函数作用，观察延时时长对闪烁效果的影响。
4. 熟悉串口通信功能与波特率设置。

二、实验环境
- 硬件：ESP32 开发板
- 软件：Arduino IDE
- 板载LED引脚：GPIO 2
- 串口波特率：115200
 三、实验内容
1. 基础闪烁程序 blink_basic.ino
程序设置 LED 每隔 1 秒点亮、熄灭一次，同时串口循环输出 `Hello ESP32!`。
运行现象：LED 节奏平缓稳定闪烁，串口监视器正常打印文本。

 2. 快速闪烁程序 blink_fast.ino
修改延时参数，将延时从 1000ms 改为 500ms，缩短亮灭间隔。
运行现象：LED 闪烁速度明显加快，串口同步输出提示信息。

四、思考题
1. 串口波特率设置不一致会出现什么问题？
答：波特率是串口数据传输的速率标准，若代码与串口监视器波特率不匹配，数据解析出错，监视器会显示乱码，无法正常查看输出内容。

2. 修改 delay() 函数内的数值，会对 LED 闪烁产生什么影响？
答：`delay()` 单位为毫秒，数值越小，LED 亮灭间隔越短，闪烁速度越快；数值越大，间隔越长，闪烁速度越慢。

五、常见问题与解决
1. 代码上传失败：按下开发板 BOOT 键再复位，进入下载模式后重新上传。
2. LED 不工作：检查开发板型号、串口端口、引脚定义是否配置正确。
